# Backup Project

## Description

Backup Project is a backup application for Windows, developed in Python.

The project is being developed alongside learning Python. Its goal is not only
to create a working backup application for everyday use, but also to learn how
to design and develop a reliable modular application.

The program is designed to create a full backup of user data from a source
directory to a selected storage location while maintaining the current backup
and previous backup snapshots.

The project focuses on:

- data safety;
- predictable backup behaviour;
- modular architecture;
- error handling;
- testability;
- future extensibility.
